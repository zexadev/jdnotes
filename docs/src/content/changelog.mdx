# 更新日志

## v1.9.1

### 优化
- **AI 配置页布局重做**：改为左侧来源列表 + 右侧详细信息双栏布局，切换查看不同来源更方便
- AI 配置：详细面板顶部新增"设为激活"按钮，非激活来源可直接切换
- AI 配置：来源卡片删除按钮 hover 时显示，平时更简洁
- 设置页整体去掉宽度限制，宽屏窗口下不再两侧大量留白

## v1.9.0

### 新增功能
- **启动自动检查更新**：应用启动后自动检查新版本，发现更新主动弹窗提示，可选择立即更新或跳过该版本

### 优化
- **数据概览页重新设计**：紧凑布局，所有核心指标 1 屏可见，无需滚动
- 数据概览：KPI 卡片配色对应编辑器 5 高亮色（笔记总数/总字数/写作天数/活跃标签/连续天数）
- 数据概览：保留写作热力图、最近 7 天趋势、24h 时段分布、Top 5 标签
- 数据概览：最近笔记列表点击直接打开对应笔记，无需先回到列表
- 数据概览跟随应用 light/dark 主题自动切换

## v1.8.1

### 修复
- 拖放图片：仅在拖放位置落在编辑器容器内时才插入，避免在侧栏等区域误触发
- 拖放图片：组件卸载时清理监听器，避免切换笔记后重复绑定
- 斜杠命令：`/` 必须在段落开头或空白后才触发，避免在词中间（如 `abc/`）误触发菜单

## v1.8.0

### 新增功能
- **富文本扩展**：编辑器支持下划线、文本高亮（5 色：黄/绿/蓝/粉/紫）、左/中/右对齐、智能排版
- **Callout 提示块**：4 种类型（信息/警告/提示/错误），可下拉切换样式
- **写作统计栏**：编辑器底部实时显示字数、字符、阅读时间、段落数（中英分别计算）
- **笔记模板**：新建笔记弹窗提供 5 个内置模板（空白/会议记录/项目计划/读书笔记/周报）
- **侧栏三态切换**：展开 → 收起（仅图标）→ 隐藏，Ctrl+\ 循环切换，状态持久化
- **斜杠命令搜索**：输入 / 后键盘字符实时过滤，命令重新分组为基础/格式/高级/AI

### 优化
- MCP Server：append/update/get 支持按 ID 精确操作（推荐先 list_notes 取 ID）
- MCP Server：get_note 支持 max_length/offset 分页截断长笔记
- MCP Server：search_notes 支持按 tag 过滤
- MCP Server：list_notes 返回内容长度
- 修正主区域 AI 助手按钮的快捷键提示为 Ctrl+L

## v1.6.0

### 新增功能
- **表格功能**：支持插入表格、调整列宽，光标在表格内时显示增删行列的气泡菜单
- **AI 联网能力**：AI 助手可搜索互联网和读取网页内容（DuckDuckGo 搜索 + 网页抓取）
- **IP 定位工具**：AI 可获取用户大致地理位置
- **Responses API 支持**：新增 OpenAI Responses API provider，支持 Azure AI Foundry、GPT-5 等
- **MCP 数据库变更通知**：MCP 写入笔记后前端实时刷新列表

### 优化
- 移除查看/编辑模式切换，笔记打开即可编辑
- AI system prompt 注入当前时间，明确联网能力说明
- 表格操作重构为气泡菜单，交互更直观
- 仪表盘图表优化

### 修复
- 修复重试和编辑消息时旧对话仍发给模型的问题
- 修复搜索结果为空的问题
- 修复表格扩展导入方式

## v1.5.0

### 新增功能
- **AI Tools 函数调用**：AI 助手可通过工具按需读取、搜索、创建、修改和删除笔记，不再把笔记内容塞进提示词
- **多对话历史**：每个笔记支持多个独立对话，可新建、切换、删除
- **图片发送**：聊天中可附加图片发送给 AI（多模态支持）
- **MCP 自动注册扩展**：启动时自动注册到 9 个 AI 工具（Claude Code/Desktop、Cursor、Windsurf、Gemini CLI、Kiro、Copilot CLI、OpenCode、Cline）

### 优化
- AI 消息用 parts 结构渲染，tool calls 穿插在文字流中显示
- 用户消息改为右对齐气泡样式
- 模型选择器移至输入框上方（类似 Cursor）
- Tools 返回结果不再包含无意义的 ID

## v1.4.0

### 新增功能
- **MCP Server 集成**：内置 HTTP MCP Server，Claude Code 等 AI 编程工具可直接将内容保存到笔记
  - 支持创建笔记、追加内容、修改笔记三个工具
  - 启动时自动注册到 Claude Code，无需手动配置
- **待办列表**：支持创建待办事项，Markdown 兼容 `- [ ]` / `- [x]`
- **编辑器固定工具栏**：文本格式、列表、引用、代码块、插入图片等常用操作
- **图片功能**：支持工具栏插入、粘贴、拖拽插入，可缩放和预览大图
- **Ctrl+Click 打开链接**：类似 VS Code 的链接交互体验
- **AI 内联模式**：重构 AI 内容插入为编辑器内联模式
- **主题切换动画**：日夜动画开关替换原有主题按钮

### 优化
- 编辑器段落间距和待办列表对齐优化
- 图片显示效果和操作体验优化
- Ctrl+Click 链接视觉反馈

### 修复
- 修复复制链接格式和自动标题 API 路径问题
- 修复 Ctrl+Click 无法打开链接的问题
