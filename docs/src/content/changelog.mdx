# 更新日志

## v2.0.0 — 多设备同步首发 🎉

> **更名说明** — 自 v2.0 起，jdnotes 正式更名为 **Lapis**。仅品牌名称变更，仍为同一应用、同一套本地数据；现有用户直接更新即可，笔记与设置原样保留，无需迁移。

Lapis 从单机笔记迈向**多设备同步**：公司、家里、未来的手机互为对端，各持全量副本，互相同步、最终一致。**不依赖任何中心服务器** —— 你的笔记永远在你自己手里。

### ✨ 核心新增

#### 🔄 多设备同步（重磅）
- **mDNS 自动发现**：同一 WiFi 下打开 Lapis 的设备互相可见，无需手输 IP
- **笔记多选同步**：设备旁「选笔记」打开多选弹窗，搜索/全选/单选要给对方的笔记
- **跨网 P2P 直连**：公司↔家不同网络也能加密直连（基于 iroh：NAT 打洞 + relay 兜底 + QUIC/TLS 端到端加密）
- **编辑器旁单条同步**：编辑器头部「推送」按钮把当前笔记直接发给某台设备
- **三路合并冲突保留双份**：改同一处自动生成「冲突副本」笔记，**绝不静默丢数据**
- **接收方推送提示**：对端推过来时本机自动 toast 告知「收到 N 条」

#### 🛡️ 同步安全与隐私
- **首次配对码确认**：配对新设备时双方屏幕显示同一个 6 位数字，对上才信任。**不靠网络协商防中间人** —— 适合咖啡店/宾馆陌生 WiFi
- **私有笔记标记**：编辑器头部 Lock 图标一键设为私有，**绝不参与同步**（个人日记、密码等不会发给任何对端）
- **持久设备指纹**：从公钥派生，重启同设备在对方眼里仍是同一台

#### 🌐 跨网体验完整化
- 跨网设备列表（添加一次记住，一键同步）
- 设备在线/离线状态（绿/灰圆点 + 刷新按钮）
- probe 自动取名（添加设备时自动取回对端设备名，无需手动填）
- 同步结果文案改双向人话：「已发出 N 条 + 本机新增 X 更新 Y」

### 💅 优化

- **图片附件化存储**：base64 内嵌 → `attachments/<sha256>` 内容寻址，DB 瘦身 + 改图不触发整篇冲突
- **「清理无用图片」**按钮：扫描笔记引用 GC 孤儿附件
- 应用启动即注册 mDNS（无需进同步页对方就能发现本机）
- 设备名变更立即同步给对方（不等 mDNS TTL 过期）
- 退出发 mDNS goodbye（对方设备列表立即清除本机）
- 多网卡同设备只列一条
- 设备同步页全局 toast 反馈 + 分区布局重做
- **搜索与日夜切换上移标题栏**：顶部即搜，侧栏品牌区贯穿到顶、左上角独立展示
- **新建即空白**：移除内置笔记模板，结构交给斜杠命令与 AI
- Agent Skill 与 MCP 注册名规整为 `lapis`

### 🐛 修复

- 修复 `local_ip()` 错选 VPN/Docker 虚拟网卡（改用 netdev 按家用私网段打分）
- 修复 `initDatabase` 未调用导致 uuid 全空、同步导出空的「新增 0」假象
- 修复 iroh 设备 ID 每次启动随机
- 修复迁移图片附件后首次同步可能假冲突爆炸（同步基准一并迁移）
- 修复复制 / 拖拽多张图片到笔记时互相覆盖

## v1.11.0

### ✨ 新增功能

#### 🔄 多设备同步：局域网自动发现 + 笔记多选同步
- **mDNS 自动发现**：同一 WiFi 下自动发现其它打开 Lapis 的设备，无需手动输 IP
- **笔记多选同步弹窗**：点设备旁「选笔记」弹模态框，搜索/全选/单选要给对方的笔记
- **编辑器旁单条同步**：编辑器头部「推送」按钮直接把当前笔记发给某台设备（iroh 跨网 / 局域网都支持）
- **持久设备指纹**：从公钥派生 fingerprint，重启同设备在对方眼里仍是同一台
- **接收方提示**：对端推过来时自动弹 toast「收到「X」推来 N 条」

#### 🌐 跨网同步完整化（基于 iroh）
- **跨网 P2P 直连**：公司↔家不同网络也能加密直连，NAT 打洞 + n0 relay 中继兜底
- **设备列表**：跨网设备添加一次记住，之后一键同步
- **设备 ID 持久化**：iroh SecretKey 存盘，重启 ID 不变
- **probe 自动取名**：添加设备时自动取回对端设备名，无需手动填名
- **设备在线/离线**：列表显示绿/灰圆点 +「刷新状态」按钮
- **三路合并冲突保留双份**：改同一处自动生成「冲突副本」笔记，绝不静默丢数据

### 💅 优化

- **应用启动即注册 mDNS**：无需打开「设备同步」页，对方就能发现本机
- **设备名变更立即生效**：改名后 mDNS 重新注册，对方刷新即看到新名字
- **退出发 mDNS goodbye**：对方设备列表立即清除本机，不等几分钟 TTL
- **多网卡同设备只列一条**：双网卡机器不再被列为两条
- **设备同步页重设计**：全局 toast 反馈、本机/跨网/局域网/其它方式分区
- 同步结果文案改双向人话：「已发出 N 条给对方 + 本机新增 X 更新 Y」
- 图片附件化存储（内容寻址 sha256），DB 瘦身 + 改图不触发整篇冲突

### 🐛 修复

- 修复 `local_ip()` 错选 VPN/Docker 虚拟网卡（改用 netdev 按家用私网段打分）
- 修复 `initDatabase` 未调用导致 uuid 全空、同步导出空的「新增 0」假象
- 修复 iroh 设备 ID 每次启动随机
