# 手机端

手机版与桌面版是同一套程序：同样的编辑器、AI 助手、日历、提醒和同步，页面按手机屏幕自适应，不是精简版。

## 安装（Android）

1. 前往 [GitHub Releases](https://github.com/zexadev/lapisnote/releases) 下载 `Lapis_x.y.z_aarch64.apk`
2. 打开安装包，按系统提示允许安装
3. 需要 Android 7.0 以上的 arm64 设备

## 安装（iOS，自签）

Lapis 不在 App Store，iOS 版以未签名 IPA 发布，需要自己签名安装：

1. 前往 [GitHub Releases](https://github.com/zexadev/lapisnote/releases) 下载 `Lapis_x.y.z_ios_unsigned.ipa`
2. 用 [AltStore](https://altstore.io)、[Sideloadly](https://sideloadly.io) 或同类工具签名并安装到手机
3. 免费 Apple ID 签出的应用 7 天过期，需按工具提示定期续签；付费开发者账号签的一年有效

有新版本时应用内会提示，点「前往下载」拿到新的 IPA 后按同样方式重新签名安装，笔记数据保留。

## 从电脑同步过来

手机端不自带欢迎笔记。已有电脑端时，配对一次即可把笔记同步到手机：

1. 电脑端打开「设置 › 设备同步」，复制「本机设备 ID」
2. 手机端打开「设置 › 设备同步 › 跨网设备」，粘贴电脑的设备 ID，类型选「我的设备」
3. 首次连接时两边各显示一组 6 位配对码，核对相同后确认
4. 之后在任一端点「同步」即可双向同步

同步通过加密 P2P 直连完成，不经过任何服务器；同一局域网内也走这条路。

## 应用内更新

启动时自动检查新版本，也可在「设置 › 软件更新」手动检查。Android 下载完成后交给系统安装器覆盖安装，笔记数据保留，首次更新时系统会要求允许 Lapis 安装应用。iOS 只提示并打开下载地址，安装仍需自签。

## 与桌面版的差异

- 数据存放在应用私有目录，不支持更改存储位置；导入、导出走系统文件选择器
- 没有托盘和 MCP Server，MCP 只在电脑上供 AI 工具接入
- 编辑器工具栏位于键盘上方，AI 提问与命令菜单的入口也在那里
- iOS 版没有真机验收过，遇到问题请到 [Issues](https://github.com/zexadev/lapisnote/issues) 反馈
