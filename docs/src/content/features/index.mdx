# 功能介绍

## 富文本编辑器

基于 TipTap 的现代编辑器，支持：
- Markdown 快捷输入
- 标题、列表、代码块、引用等
- 斜杠命令快速插入内容

## 笔记引用与双向链接

- 输入 `[[` 弹出笔记选择框，选中即插入引用
- 单击引用直接跳转到目标笔记
- 被引用的笔记底部自动显示「被以下笔记引用」反向链接
- 引用基于稳定 ID，跨设备同步、导入导出后依然有效
- 标签自动配色：同一标签在侧栏与编辑器中颜色恒定，无需手动设置

## AI 辅助

- 多模型支持：OpenAI 兼容、Anthropic Claude、Google Gemini、Ollama
- 多来源配置：同时保存多个 AI 来源，一键切换
- 气泡菜单：选中文本即可改进、翻译、总结
- AI 对话：右侧聊天面板，结合笔记上下文对话，可调用工具读写笔记、联网搜索；对话标题自动总结（手动改过的不覆盖）；图片可粘贴、拖入或点选附加，点击可放大预览
- 上下文压缩：长对话一键压缩成摘要继续聊，接近模型窗口上限时发送前自动压缩；面板实时显示占用进度条。窗口大小按模型自动识别（GPT-4o 128k、Claude 200k、Gemini 1M…），也可在来源里手填
- 稳定可靠：网络抖动 / 限流自动重试，工具结果超预算自动折叠

## MCP Server 集成

让 AI agent 直接在你的本地笔记库**写入**（创建 / 追加 / 修改），而不只是只读问答 —— 这是 Lapis 区别于多数本地笔记工具的地方。

- 内置 HTTP MCP Server，启动时自动运行
- 自动注册到 Claude Code、Cursor、Windsurf 等 9 个 AI 工具
- 6 个工具：读取（get_note、search_notes、list_notes）+ 写入（create_note、append_note、update_note）
- Agent Skill 自动安装：启动时自动安装到 Claude Code、Copilot、Gemini CLI

## 数据管理

- 本地 SQLite 存储，数据完全离线
- 支持自定义存储位置
- JSON 导入导出
- 选择性导出笔记

## 提醒通知

- 笔记内设置提醒时间
- 系统通知弹窗提醒
